# 数据加载与本机存储

## 应用装配

`ReaderAppRoot` 为每个窗口注入 `AppContainer`、`LibraryStore` 和 SwiftData 容器，应用外观偏好在根部生效。所有页面通过 `ReaderRoute` 进入统一详情；iPhone 每个 Tab 保存独立路径，iPad/macOS 使用栏目、列表、详情三栏。

## 请求生命周期

1. 进入前台并行加载精选首页、热点、最新日报。页面先读取缓存，再按新鲜度请求。
2. 前台每 60 秒检查一次；搜索输入和正在加载、分页的列表不受定时刷新打断。热点和日报仍受各 URL 的新鲜度约束。
3. `APIClient` actor 按完整 URL 合并请求；取消一个等待者不取消其他等待者，最后一个等待者取消时终止请求。
4. JSON 只请求 `https://aihot.news/api/v1/`。事件网页仅用于提取 ID，308 只允许跳到同域 JSON 事件端点。
5. 200 先校验类型和可解码性，再写缓存；304 保留正文；429/503 设置全客户端 `Retry-After` 冷却时间。
6. 可见页面的状态视图在冷却结束后重试，页面消失会取消等待。网络失败有缓存时继续显示内容；分页失败保留已有行和当前游标。

后台使用 SwiftUI `backgroundTask(.appRefresh)` 和 `BGTaskScheduler`，只请求默认精选首页、热点和最新日报，遵守缓存新鲜度。最早下一次请求为 15 分钟后，实际运行时间由 iOS 决定。

## 网络缓存

`ResponseCache` 是独立 actor，使用原子文件写入；默认上限 128 条响应、20 MiB。未收藏列表和事件保留七天，指定日期日报可长期保留，容量不足仍可淘汰最旧响应。

| 场景 | 行为 |
| --- | --- |
| 内存分页 | 游标按完整查询绑定，同一上海日历日内使用；跨日或换查询丢弃 |
| 磁盘列表 | 将已浏览页合并为当前查询的离线列表；不保存带 cursor 的 URL、nextCursor 或 ETag |
| 冷启动 | 先显示离线列表，重新验证首页后建立新的内存分页状态 |
| 返回或重新验证已翻页列表 | 同查询、同上海日且首页仍新鲜或收到正文未变化的 304 时，保留已加载页和下一页游标；304 不删除续页离线副本 |
| invalid_cursor | 保留原筛选，重新请求首页，不扩大查询范围 |
| 最新日报 | 同时按响应返回的日期写入归档缓存，不猜日期 |
| 日报出刊 | latest 和索引的缓存新鲜度不越过下一次上海时间 08:00 |
| no-store | 不存储响应并删除对应旧缓存 |
| 404 | 删除对应未收藏网络副本，包括事件重定向别名 |
| 清除缓存 | 取消在途请求并递增代次，旧请求不能重新写回；收藏与已读独立保留 |

`selected/snapshot` 和 `selected/changes` 仅保留契约模型与端点支持，不落盘，也不用于后台全量同步。

## 收藏与已读

`LibraryStore` 在 MainActor 上显式保存 SwiftData。收藏保存条目、事件、日报的完整 Codable 快照及来源字段，已读只保存类型、ID 和时间。写入失败回滚并显示错误，不重置用户数据库。

事件发生 308 合并时，收藏和已读原子迁移到新的 publicId；当前阅读路径通过别名继续定位收藏。上游 404 后仍可阅读明确标注的本机收藏副本。

## 深链

支持 `aihotnews://feed`、`hot`、`daily`、`my`，以及 `item/<id>`、`story/<id>`、`daily/YYYY-MM-DD` 和 `search?q=<关键词>`。

搜索深链返回精选根页并打开搜索框，沿用当前筛选。仅接受一个 `q` 参数，去除首尾空白后须为 2–200 个 Unicode 码点；重复参数和其他参数会被拒绝。

条目仅使用本机快照；事件 ID 必须能在热点、收藏或事件缓存中找到上游引用。没有本机内容时显示说明，不猜造单篇正文接口或网页地址。日期格式会严格校验，转义后的路径片段也要经过验证。

## 测试入口

离线契约、网络、功能状态、SwiftData 测试在 `AIHotNewsTests`。`AIHotNewsUITests` 覆盖资讯、事件、日报收藏，重启后的离线读取，搜索空态与搜索深链，深色最大辅助功能字号与自适应导航，并保存截图附件。

UI 测试通过 DEBUG 专用参数 `--ui-test-session <UUID>` 使用独立数据库和响应缓存；`--ui-offline` 模拟断网。发布构建不包含该传输实现，正常启动始终使用真实 API。

真实接口冒烟测试使用 AGENTS.md 中的 `AIHOT_LIVE_API_TESTS` 命令。模拟器测试建议加 `-parallel-testing-enabled NO`，避免当前 Xcode 自动创建的并行克隆设备启动失败。
